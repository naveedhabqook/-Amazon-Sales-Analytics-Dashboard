# -Amazon-Sales-Analytics-Dashboard
Interactive Amazon Sales Analytics Dashboard built with Power BI to analyze revenue, orders, customers, categories, brands, and payment methods.

## 📖 Overview

This project is an interactive **Amazon Sales Analytics Dashboard built in Microsoft Power BI** using a 100,000-record e-commerce sales dataset.

The dashboard analyzes revenue, orders, customers, categories, brands, payment methods, and order statuses to provide a clear view of overall sales performance and business trends.

## 📊 Key Insights

* 💰 **Total Revenue:** 91.83M
* 🛒 **Total Orders:** 100K
* 👥 **Total Customers:** 43K
* 📊 **Average Order Value:** 918.26
* 📦 **Electronics** generated the highest revenue among the categories, at approximately **15.58M**.
* 💳 **Credit Card** generated the highest revenue among payment methods, at approximately **32.12M**.
* 🚚 **Delivered orders** represented approximately **75%** of all orders.
* 📈 Revenue was relatively consistent across the years, with **2020** generating approximately **18.53M**.
* 🏷️ Revenue across the leading brands was relatively evenly distributed.

## 🚀 How to Use

1. Clone this repository.
2. Open the `.pbix` file using **Power BI Desktop**.
3. Connect the report to the provided Amazon sales Excel dataset if required.
4. Refresh the data.
5. Explore the dashboard and analyze sales performance.

## 📌 Analysis Areas

### 💰 Revenue Analysis

The dashboard analyzes total revenue across categories, brands, payment methods, and years to identify major revenue contributors.

### 📈 Revenue Trends

Annual revenue is compared across **2020–2024** to identify changes and overall sales patterns.

### 📦 Category Analysis

Revenue is compared across categories including Electronics, Sports & Outdoors, Books, Clothing, Toys & Games, and Home & Kitchen.

### 🏷️ Brand Analysis

Revenue is analyzed across multiple brands to compare brand-level performance.

### 💳 Payment Method Analysis

The dashboard compares revenue generated through:

* Credit Card
* Debit Card
* UPI
* Amazon Pay
* Net Banking
* Cash on Delivery

### 📋 Order Status Analysis

Orders are categorized as:

* Delivered
* Shipped
* Pending
* Returned
* Cancelled

This provides an overview of order fulfillment and customer transaction status.
